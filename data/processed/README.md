# Processed Data

This directory stores datasets generated by the Movie Intelligence ETL pipeline.

Unlike `raw_data/`, which contains the original Kaggle CSV files, this directory contains data produced through extraction, cleaning, transformation, and validation.

## Purpose

- Store cleaned and transformed datasets.
- Keep processed outputs separate from original source files.
- Support reproducible data processing.
- Store relevant metadata and validation artifacts.

## Current Contents

Currently, this directory contains:

- `raw_data_fingerprints.json` — SHA-256 fingerprints of the original raw CSV files, used to verify their integrity.

**Note:** All processed datasets must be generated through the Python ETL pipeline. Original raw CSV files should never be manually modified.
