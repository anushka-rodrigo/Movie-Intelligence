# Movie Intelligence Platform

An analytical platform for understanding movies and audience behaviour, with predictive and recommendation capabilities.

Built on [The Movies Dataset](https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset) from Kaggle (45,000+ movies, 26 million ratings from 270,000+ users).

## What it will answer

- **Movie economics:** budget, revenue, profit and ROI
- **Audience behaviour:** ratings, rating distributions, popularity
- **Industry analysis:** genres, directors, cast, release periods, languages
- **Prediction and recommendation:** revenue prediction and movie recommendations

## Planned architecture

```
Kaggle raw data → Python ETL → PostgreSQL → SQL analytics / statistics / ML
                                          → FastAPI → Streamlit dashboard → Docker + AWS
```

## Tech stack

Python, SQL, PostgreSQL, pandas, NumPy, SciPy, statsmodels, scikit-learn, FastAPI, Pydantic, SQLAlchemy, Streamlit, Docker, AWS, pytest
